Conditional Formatting Guide

Powerful Data Highlighting with Natural Language

How It Works

Simply ask your question and mention what you want to highlight. Our AI will automatically apply color coding to both your chat results and Excel exports. No complex formulas needed!

🔑 Trigger Words: Include any of these keywords in your question to activate conditional formatting:
highlight color red yellow green warn flag
TIER 1

Basic Conditions

Numeric Comparisons

Highlight values based on numeric thresholds using <, >, <=, >=, ==, or !=

Example Query
"Show me sales by region and highlight anything below $1M in red"
Below threshold

Text Exact Match

Highlight rows where text matches exactly (case-insensitive)

Example Query
"Show all reports and highlight ones owned by Thiago Alvares in yellow"
Exact match

Null or Empty Values

Identify missing data by highlighting null or empty cells

Example Query
"Show customer list and highlight missing email addresses in red"
Missing data
TIER 2

Intermediate Conditions

Text Contains/Starts/Ends

Flexible text matching: contains substring, starts with, or ends with specific text

Example Query
"Show project list and highlight anything containing 'Forecast' in green"
Pattern match

Date Comparisons

Compare dates to find overdue items, upcoming deadlines, or specific date ranges

Example Query
"Show tasks and highlight anything due before today in red"
Overdue items

Row-Level Highlighting

Highlight entire rows instead of just individual cells when conditions match

Example Query
"Show all projects and highlight entire rows where status is 'Failed' in red"
Full row
TIER 3

Advanced Conditions

Top N / Bottom N

Automatically find and highlight the highest or lowest N values

Example Query
"Show revenue by customer and highlight the top 5 in green"
Top performers
Bottom performers

Cross-Column Comparison

Compare two columns and highlight where one exceeds the other

Example Query
"Show budget vs actual and highlight where actual exceeds budget in red"
Over budget

Multiple Conditions (AND)

Combine multiple criteria - all conditions must be true

Example Query
"Show tasks and highlight where status is 'Failed' AND priority is 'High' in red"
All conditions met

Pro Tips for Best Results

  • Be specific about what you want highlighted and which color to use
  • Combine multiple conditions in one query: "highlight X in red and Y in green"
  • Works in both chat tables and Excel exports - same formatting everywhere
  • Column names must match exactly as they appear in your data
  • Use "entire row" or "whole row" to highlight full rows instead of individual cells
  • Try different color combinations: red for warnings, yellow for caution, green for success
  • Formatting persists when you refine your question or export to Excel
