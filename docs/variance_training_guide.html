Welcome to Multi-File Analysis

The Variance tab enables you to analyze and link multiple data files together. Whether you're comparing budgets to actuals or merging customer data with sales records, you can work with up to 4 files simultaneously.

Understanding the Interface

File Upload Sections

1 FILE 1 through FILE 4

Generic file slots that can hold any dataset. You can customize the labels (e.g., "Budget 2024", "Actuals Q1").

  • Click or drag files to upload
  • Supported formats: Excel (.xlsx, .xls), CSV
  • Maximum file size: 50MB per file
  • Minimum 2 files required to ask questions

Smart Join Suggestions

After uploading files, the system analyzes columns and suggests potential joins:

  • High confidence: Column names match exactly (e.g., "CustomerID" in both files)
  • Medium confidence: Similar names (e.g., "CustID" and "CustomerID")
  • Value overlap shown: "95% of values match" indicates good join quality

Actions:

  • ✓ Use this join - Accept and save the suggestion
  • ✗ Reject - Dismiss this suggestion

Comparison Configuration Panel

Shows current status and allows manual control:

  • Uploaded Files: List of all loaded files
  • Active Joins: Accepted join relationships
  • Analysis Mode: Variance or Linking (auto-detected)
  • Manual Mode: Override auto-detection if needed

Quick Data Exploration Buttons

Pre-configured questions that auto-execute when clicked:

  • List Columns/Joins: Shows available columns and active join relationships
  • Sample Data: Displays first 5 rows from each file
  • Record Counts: Shows row counts for each file and after joining

Key Features

1. Multi-File Upload (2-4 Files)

Use cases:

  • Traditional variance: Budget vs Actuals (2 files, same structure)
  • Multi-file linking: Customers + Sales + Products (3 files, different structures)
  • Quarterly comparisons: Q1, Q2, Q3, Q4 data (4 files)

2. Smart Join Detection

How it works:

  • System analyzes column names across all files
  • Uses fuzzy matching to find similar names
  • Checks value overlap (how many IDs actually match)
  • Prioritizes ID/Code columns for suggestions
  • Ranks suggestions by confidence

Example suggestion:

File 1 'CustomerID' ↔ File 2 'CustomerID'
Confidence: High | Value overlap: 98%

3. Automatic Mode Detection

Variance Mode

Activated when:

  • Only 2 files uploaded
  • Schemas are 80%+ similar
  • No explicit join hints

Focus: Comparing values across same-structure files (variance calculations)

Linking Mode

Activated when:

  • 3 or 4 files uploaded
  • OR 2 files with different schemas
  • OR explicit join hints provided

Focus: Merging different datasets via join operations

4. Natural Language Joins

If no auto-suggestions appear, specify joins in your question:

  • "Link File 1 CustomerID to File 2 CustID"
  • "Join on AccountNum to AcctID"
  • "CustomerID = CustID"

The system parses these patterns and applies the joins automatically.

5. Conditional Formatting in Excel Exports

When you export results to Excel, conditional formatting is applied based on the analysis:

  • Top/Bottom values: Highlighted in green/red
  • Variance thresholds: Over budget shown in red
  • Null checks: Missing values highlighted
  • Date ranges: Current period highlighted
  • Cross-column rules: Budget vs Actual comparisons

Tips & Best Practices

File Preparation

⚠ Data Quality Tips:
  • Clean column names: Remove spaces, special characters before upload
  • Consistent formats: Dates, numbers should use same format across files
  • ID columns: Make sure join keys have matching values (not just names)
  • Remove duplicates: Duplicate IDs can cause incorrect join results

When to Use Each Mode

Use Variance Mode for:

  • Budget vs Actuals comparisons
  • Period-over-period analysis (This Year vs Last Year)
  • Forecast vs Actual tracking
  • Any scenario where structures are identical

Use Linking Mode for:

  • Master data enrichment (Customers + Transactions)
  • Multi-system integration (CRM + ERP data)
  • Hierarchical data (Departments + Employees + Projects)
  • Any scenario where schemas differ

Troubleshooting

If joins aren't suggested:
  • Check column names - are they similar enough?
  • Verify value overlap - do IDs actually match?
  • Use natural language joins in your question
  • Consider manual mode if needed
If wrong mode is detected:
  • Enable "Manual Mode" in Comparison Configuration panel
  • Select desired mode (Variance or Linking)
  • System will respect your choice
If questions fail:
  • Ensure minimum 2 files are uploaded
  • Verify joins are accepted (check Active Joins list)
  • Try simpler questions first to test connectivity
  • Check file uploads completed successfully
